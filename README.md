# Image-Classification-CNN
A deep learning project that uses Convolutional Neural Networks (CNNs) to classify images into predefined categories by automatically learning visual features from image data.

## Getting Started

### Moving Files to Root Directory
If you need to move files from a subfolder to the root directory of this project, see [MOVE_FILES_GUIDE.md](MOVE_FILES_GUIDE.md) for detailed instructions.

Quick start:
```bash
# Option 1: Use the helper script
python move_files.py <subfolder_name>

# Option 2: Use git commands
git mv subfolder/* .
git commit -m "Move files to root"
git push
```
